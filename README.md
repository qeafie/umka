# Умка

**Удобный мобильный коммунальный ассистент.** Умка помогает жителям разобраться с бытовыми ситуациями, сохранить показания счётчиков и подготовить обращение в УК или ТСЖ.

Сейчас доступны инструкции по аварийным ситуациям, подготовка текста обращения, вход с проверкой данных запуска MAX и личный журнал счётчиков. Показания сохраняются только в Умке и не отправляются поставщикам; официальный MAX-запуск требует токена бота и подключения приложения на платформе.

## Стек

- Laravel 13, PHP 8.4, Inertia 3.
- Vue 3 (Composition API, JavaScript), Tailwind CSS 4, Vite 8.
- Laravel Sail / Docker Compose, PostgreSQL 18, Node.js 24.
- PHPUnit 12 и Vitest 4 / Vue Test Utils. Тестовая БД — SQLite в памяти.

Версии зависимостей зафиксированы в `composer.lock` и `package-lock.json`.

## Запуск одной командой

Нужны Git, Bash и запущенный Docker с Docker Compose v2. Локальные PHP, Composer и Node.js не обязательны. На первом запуске нужен интернет для загрузки образов и пакетов.

```bash
git clone --branch setup/laravel13 https://github.com/qeafie/umka.git
cd umka
./bin/setup
```

`./bin/setup` создаёт `.env`, устанавливает Composer-зависимости через Docker, собирает и запускает Sail / PostgreSQL, генерирует ключ приложения, применяет миграции, устанавливает npm-зависимости, собирает фронтенд и подключает Git hooks. При повторном запуске существующий ключ и данные сохраняются. Пароль БД из примера предназначен только для локального окружения.

Откройте [http://localhost:8000](http://localhost:8000). Должны появиться название «Умка» и домашние сценарии. [http://localhost:8000/up](http://localhost:8000/up) должен вернуть HTTP 200.

## Разработка

После первоначальной настройки:

```bash
./vendor/bin/sail up -d
./vendor/bin/sail npm run dev
```

Vite работает в текущем терминале. Остановить его можно через `Ctrl+C`. Для работы без Vite выполните `./vendor/bin/sail npm run build`.

```bash
./vendor/bin/sail down
```

Эта команда останавливает окружение, сохраняя БД. Повторный запуск — `./vendor/bin/sail up -d`. Не добавляйте `-v`, если данные нужно сохранить: этот флаг удаляет тома.

## Окружение и порты

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `APP_NAME` | `Умка` | Название приложения |
| `APP_URL`, `APP_PORT` | `http://localhost:8000`, `8000` | Адрес и порт приложения |
| `APP_KEY` | Генерируется при настройке | Ключ шифрования Laravel |
| `APP_ENV`, `APP_DEBUG` | `local`, `true` | Режим локальной разработки |
| `VITE_PORT` | `5175` | Vite / HMR |
| `DB_CONNECTION`, `DB_HOST`, `DB_PORT` | `pgsql`, `pgsql`, `5432` | PostgreSQL внутри Docker |
| `DB_DATABASE`, `DB_USERNAME` | `umka`, `sail` | Локальная БД |
| `DB_PASSWORD` | `password` | Демонстрационный локальный пароль |
| `FORWARD_DB_PORT` | `5433` | Доступ к БД с хоста |
| `WWWUSER`, `WWWGROUP` | `1000`, `1000` | UID/GID пользователя Sail; на Linux согласуйте с владельцем файлов |
| `INERTIA_SSR_ENABLED` | `false` | SSR на этом этапе отключён |

Порты опубликованы только на `127.0.0.1`. При смене `APP_PORT` обновите также `APP_URL`. Все параметры перечислены в `.env.example`; секреты задавайте только в `.env`, который исключён из Git. Конфигурация Docker предназначена для локальной разработки.

## TDD и проверки

1. Написать тест нового поведения.
2. Запустить его и убедиться, что он падает по ожидаемой причине.
3. Написать минимальную реализацию.
4. Получить зелёные тесты, затем рефакторить.
5. Проверить полный набор перед коммитом и после него.

```bash
./bin/test
./vendor/bin/sail artisan test --filter=HomePageTest
./vendor/bin/sail npm run test:watch
./vendor/bin/sail composer lint:check
./vendor/bin/sail npm run build
```

Если PHP 8.4+ и Node.js 24 установлены локально, после установки зависимостей доступен `./bin/test --local`.

Backend-тесты проверяют страницы и навигацию Inertia, подпись запуска MAX, сессии, доступ к счётчикам, изоляцию данных по пользователям и проверку истории показаний. Vue-тесты проверяют основные сценарии, загрузку и интерфейсные состояния. Тестовая БД не использует локальную PostgreSQL.

Для получения токена чат-бота задайте `MAX_BOT_TOKEN` в `.env`. Ключ инициализации MAX проверяется на сервере по [официальному алгоритму подписи](https://dev.max.ru/docs/webapps/validation). Для промоматериалов доступны [логотип](public/brand/umka-logo.svg), [знак](public/brand/umka-mark.svg) и [маскот](public/brand/umka-mascot.svg); описание бренда — в [docs/brand.md](docs/brand.md).

## Git

Работать только в отдельных ветках, например `feature/add-incidents`. Сообщения коммитов короткие: `Инициализация проекта`.

```bash
git config core.hooksPath .githooks
git switch -c feature/add-incidents
```

`pre-commit` запрещает коммиты в `main` / `master` и detached HEAD. `post-commit` запускает PHP- и Vue-тесты в Sail после каждого коммита. Поэтому контейнеры должны работать. Post-commit не отменяет уже созданный коммит: при ошибке исправьте проблему до push. После нового клонирования hooks нужно подключить через `./bin/setup` или указанную команду.

GitHub Actions запускает тесты, проверку форматирования PHP и сборку фронтенда на push и pull request. Защита основной ветки на GitHub настраивается отдельно владельцем репозитория.

## Архитектура и данные

`routes/web.php` → Inertia middleware → `resources/js/pages/Home.vue`. Единственный сервер Laravel и единственная БД PostgreSQL. Зависимости npm в Docker хранятся отдельно от хостовых, чтобы не смешивать нативные пакеты macOS и Linux.

Применяются стандартные миграции Laravel для пользователей, сессий, кеша и очередей, а также для журнала счётчиков и показаний. Справочник аварийных инструкций хранится в конфигурации. Личные записи счётчиков пока не синхронизируются с поставщиками и ГИС ЖКХ. PostgreSQL хранит данные в томе `umka_sail-pgsql`; `DatabaseSeeder` оставлен пустым.

Материалы «Умный город» использованы как контекст продукта. Рекомендованный в материалах React заменён на Vue по явному выбору пользователя. Для реального запуска внутри MAX ещё нужно подключить бот и проверить приложение в платформе.

Официальная документация: [Laravel 13](https://laravel.com/docs/13.x), [Inertia 3](https://inertiajs.com/docs/v3/installation/client-side-setup), [Laravel Sail](https://laravel.com/docs/13.x/sail).
